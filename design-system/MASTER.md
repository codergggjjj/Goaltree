# Goalflow Design System

## 视觉性格

关键词：年轻、像素二次元、日系 RPG、原生 App 感、清晰、轻操作。界面使用硬边像素阴影、有限色板与原创动漫助手，信息层级仍优先于装饰；不使用 emoji 充当功能图标。

## 颜色令牌

| 令牌 | 亮色值 | 用途 |
|---|---|---|
| `--canvas` | `#F6F3FF` | App 内容背景 |
| `--surface` | `#FFFDFB` | 主要卡片 |
| `--surface-soft` | `#EEEBFF` | 次级分组 |
| `--ink` | `#211E3A` | 主文本与像素描边 |
| `--ink-soft` | `#625D78` | 次文本 |
| `--primary` | `#6254D9` | 主操作和实际进度 |
| `--primary-deep` | `#40369C` | 高强调 |
| `--cyan` | `#23849A` | 计划进度和信息状态 |
| `--amber` | `#A85D00` | 重点提示 |
| `--success` | `#177359` | 正常/成功 |
| `--danger` | `#B53B52` | 高风险/错误 |
| `--line` | `#373154` | 像素描边 |

所有状态同时展示图标或文本，禁止只用颜色表达。正文与背景对比度至少 4.5:1。

## 字体与尺寸

- 正文使用 `Inter, "Noto Sans SC", "Microsoft YaHei", sans-serif`；阶段标签和数据使用系统等宽字体形成像素节奏。
- 正文 16px/1.6；辅助文字 14px；最小标签 12px，仅用于非正文元信息。
- 标题使用 600–750 字重，数据数字启用等宽数字。
- 尺寸阶梯：12 / 14 / 16 / 18 / 24 / 32 / 40。

## 形状与层级

- 主卡片使用 2–3px 深色硬边、0–4px 小圆角和 4–8px 无模糊硬阴影；输入控件可保留 4px 小圆角。
- 外层在桌面端表现为一个独立 App 窗口，使用 96px 图标栏；移动端使用全屏 App 壳与四项底部标签栏。
- 间距遵循 4/8px 系统，页面区块主要使用 24/32px。
- 桌面内容最大宽度 1440px；侧栏 240px；移动端使用底部导航。

## 动效

- 微交互 160–240ms，只动画 `transform` 和 `opacity`。
- 页面只允许 1–2 个强调动效；数据更新使用短暂淡入。
- 必须支持 `prefers-reduced-motion`，禁止动效阻塞操作。

## 组件约束

- 功能图标统一使用 Lucide 2px 描边。
- 点击目标至少 44×44px，键盘焦点环 3px。
- 表单始终显示 label，错误紧邻字段并保留输入。
- 每个页面仅一个主要 CTA；破坏性操作与常规操作分离。
- 图表提供文字摘要、单位、图例和可读的数据替代。

## 二次元元素使用规则

- 使用原创像素动漫助手“小光”：蓝紫短发、琥珀色眼睛、星图导航制服和四角星发夹。
- 角色用于首页主线卡、空状态和复盘完成反馈；不进入密集表单或图表内容层。
- 可以借鉴日系动漫与 RPG 的氛围，但不得复制雷姆等既有角色的脸、发饰、服装、标志或剧情身份。
- 不使用受版权保护的角色图像、品牌图像或表情符号。
- 图表和表单区域不放置高对比插画，避免干扰信息阅读。

## 响应式与无障碍

- 验证宽度：375、768、1024、1440px；移动端不得横向滚动。
- 图标栏在小于 768px 时改为四项底部导航；设置从右上角头像进入，减少一级导航数量。
- 首页只保留一个主要 CTA，常用动作以“记进展 / 做复盘 / 调计划”三个一触入口呈现。
- 固定导航为内容预留安全空间。
- 支持键盘操作、跳过导航链接、语义标题、ARIA 标签与减少动效。
